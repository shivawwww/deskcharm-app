Map settings

There is no keyless Google map API. To use Google: in Google Cloud Console create a project, enable "Maps JavaScript API", create an API key, and restrict it to this site's HTTP referrer and to that one API. Google asks for a billing account but includes free monthly usage; check its current pricing. A key in a web page is visible to visitors, which is why the referrer restriction matters. The key is stored only in this browser and sent only to Google. If Google fails, the page falls back to OpenStreetMap.
